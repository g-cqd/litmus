# litmus 0.4.10 (from 0.4.8)

Adopts `AemiIO.FileLock` and `analyzerkit` AST `LocalDependencies`/`SourcePath.commonAncestor` (T-ECO-4), and fixes two regressions caught during real-world iOS benchmarking: preserves skipped view-builder site counts across `RunSession` into `run.json` and Markdown reports, and includes sole-statement SwiftUI leaf views inside conditional/switch/body blocks (such as `if let error { Text(error) }`) in `remove-view-element` and skipped-site counts.

## Behaviour

- `RunSession` forwards `clonePlan.skipped` onto the final `MutationPlan` stored in `RunArtifact`.
- `BuilderContext.isLeafViewElement` now accepts sole leaf statements directly inside `if`, `switch`, accessor, or `@ViewBuilder` function bodies while continuing to exclude container wrappers (`Section`, `VStack`, …), imperative action closures, and arbitrary single-statement closures (such as `.map { ... }`).

## Findings that may appear

With `--operators remove-view-element`, conditional leaf views like `if let error { Text(error) }` are now mutated.
