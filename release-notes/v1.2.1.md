## Behaviour

- With `--diff`, `--diff-base` and `--diff-scope lines`, a changed line counts only if it holds code: a token, not only comments or blank space. Before, editing a comment inside a multi-line mutant planned that mutant. For example, a comment inside a `Task { … }` planned the removal of the whole `Task`. `--diff-scope files` still mutates every site of a changed file, whatever changed in it.
- Two operators that make the same replacement of the same span are one mutant, kept under the lower tier's operator. For example, `return-boundary` and `replace-nil-coalescing` both turn `a ?? ""` into `""`.
