# litmus 0.4.11 (from 0.4.10)

Refines SwiftUI leaf view-element detection in `BuilderContext` so modifier-chained container wrappers (such as `VStack { ... }.accessibilityElement(...)`) and chained action modifiers (such as `.onAppear { ... }`) are accurately excluded from `remove-view-element` and skipped-site counts.

## Behaviour

- `BuilderContext.isLeafViewElement` unwraps chained view modifiers via `rootCall(of:)` before checking for container trailing closures, so `VStack { ... }.accessibilityElement(...)` is recognized as a container wrapper rather than a leaf view element.
- `BuilderContext.isInsideActionClosure` inspects the immediate callee name (`immediateCalleeName`) rather than the root call of a modifier chain, so imperative statements inside chained `.onAppear { ... }` / `.task { ... }` / `.onChange { ... }` modifiers are properly excluded.

## Findings that may disappear

With `--operators remove-view-element`, duplicate container-level mutants on modifier-chained containers (e.g. `VStack { ... }.padding()`) are no longer emitted alongside their leaf children.
