## Behaviour

- **Action closures in view bodies are mutated as code.** `Button` actions, `.onChange`, `.task` and the other action modifiers, `Task { }`, `withAnimation`, closures labelled `action:`, `perform:` or `onDismiss:`, and closures holding assignments, `try`, `await`, `guard`, `defer` or `return` now get `remove-call`, `empty-closure-body` and the other logic operators. Before, everything inside `var body` was treated as view content, so a `Task { … }` in an `.onChange` was never removed.
- **Waits are not removed.** `sleep`, `usleep`, `nanosleep`, `Task.sleep`, `Thread.sleep` and `Task.yield` change only timing, so their mutants were noise.
- **One mutant per negated comparison.** When `replace-relational` mutates a comparison, `negate-condition` and `swap-ternary` no longer add `!(comparison)`: it is the same mutant as the relational complement (`a < b` to `a >= b`).
- **Narrowed Xcode builds.** Under `xcodebuild`, Litmus edits the scheme and test plan in the workspace copy down to the test targets the package and project graph names for the mutants (or `--test-target`), so only those bundles and their dependencies build. `-only-testing:` does not narrow `build-for-testing`, which is why the scheme is edited. Measured on an iOS app with fourteen test bundles: 478 s instead of 1,188 s. Never in place, and never when a mutant's file has no known covering test target.
- **`--simulators` recovers from a stalled device.** Clone versus create is now decided from the template simulator's current state; the helper may have booted it since the destination was resolved, and a booted simulator cannot be cloned. If the unmodified suite times out on a simulator Litmus made, the run retries once on the destination's own simulator and keeps it. A failing `simctl clone` or `create` now reports its error message.

## Findings that may appear

- `remove-call` and other logic mutants inside view action closures.

## Findings that may disappear

- `remove-call` on waits.
- The `!(comparison)` duplicate of a relational mutant.
