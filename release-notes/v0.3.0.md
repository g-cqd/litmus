# litmus 0.3.0 (first release)

Mutation testing for Swift packages and Xcode projects. This release includes changed-line scope, incremental workspaces, verified result reuse, execution budgets, survivor baselines, and CI report formats.

## Flags

- `run`: `--diff`, `--diff-base`, `--diff-root`, `--diff-strip`, `--diff-scope lines|files`; `--budget`,
  `--max-mutants`; `--unmutated-baseline`; `--result-store`, `--store-read-only`, `--store-limit`, `--reuse
  closure|declaration`, `--resume`, `--reach-from`; `--workspace copy|in-place|persistent:<dir>`, `--build-directory`;
  `--shard k/n`; `--no-simulator-helper`; `--xcodebuild-argument`; `--report`, `--baseline`, `--gate new-survivors`.
- `plan`: the diff options.
- `analyze`: `--format markdown|stryker`, `--baseline`, `--write-baseline`, `--gate new-survivors`, the diff options.
- `run`: `--package-path` selects a package inside the snapshot root; `--test-plan` selects an explicit Xcode test plan.
- `check`: inspect package paths, shared schemes/test plans, and existing `.xctestrun` files without building.
- New commands: `litmus merge` (shards), `litmus restore` (an interrupted in-place run).

## Exit codes

none: `0` passed, `1` findings (with `--report`, survivors under `--gate`), `64` usage, `70` incomplete, stale or
unresolved, `74` output, `78` configuration. A run stopped by `--budget` or `--max-mutants` exits `0` and lists what it
did not test.

## Report

- The run artifact adds `cost`, `budget`, `reuse`, `shard`, `plan.scope`, `testCounts`, and per result `reuseKey` and
  `reusedFrom`; the policy adds `baselineBuild`. Execution policy v4 (`…/inactive-schema-baseline/v4`): artifacts of
  earlier policies are refused by `analyze`.
- Mutant ids are anchored to the code (path, declaration, normalised text, ordinal): they survive lines added above.
- SARIF adds `partialFingerprints["litmus/anchored/v1"]`; Markdown and Stryker's mutation-testing-report-schema 2.

## Cache

The result store (`--result-store`) is new: one verified record per reuse key, signed with HMAC-SHA256 when
`LITMUS_STORE_KEY` is set, least recently used evicted past `--store-limit` (1024 MiB). Keys include the tool version,
so a new version starts empty.

## Findings that may appear

- A crashed test runner or host under `xcodebuild` is now `crashed`, not `killed`.
- Per-test reach (when known) rejects a kill by tests that do not reach the mutant: such a mutant is decided again, and
  may become `survived`.

## Findings that may disappear

- With a diff, findings outside the changed lines are out of scope; with `--baseline`, survivors the base branch's
  baseline holds are suppressed.
