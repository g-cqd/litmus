# litmus 0.7.1 (from 0.6.0)

The v0.7.0 tag never published (a test time limit failed on the release runner); 0.7.1 is the same release with that limit raised. Completes Phase F: SwiftUI UI-domain operators (`--ui-operators`), zero-setup XCUITest target-app activation via `.xctestrun`, result-store management (`litmus store status|gc|pack|unpack`), GitHub Actions workflow annotations (`analyze --format github`), duration-balanced `--shard` partitioning with `--reach-from`, event-driven shared-process workers, and documented CLI/schema stability guarantees.

## Behaviour

- **Phase F1 (`--ui-operators`).** Adds `negate-disabled` (`.disabled(...)`), `remove-presentation` (`.sheet`, `.fullScreenCover`, `.popover`, `.alert`, `.confirmationDialog`, `.navigationDestination` preserving opaque `some View` types via `.constant(false)` / `.constant(nil)` / `ViewBuilder` guards), and `remove-view-action` (`.onAppear`, `.onDisappear`, `.task`, `.refreshable`, `.onSubmit`, `.onChange`).
- **Phase F2 (zero-setup XCUITest bridge).** `XcodeHarness` injects `LITMUS_ACTIVE_ID_<token>` and `LITMUS_COVERAGE_DIR_<token>` into `UITargetAppEnvironmentVariables` for UI test bundles in `.xctestrun`, so `XCUIApplication().launch()` receives active mutant and coverage settings automatically without app or test-code boilerplate.
- **Phase F3 (CI scale & store CLI).** Adds `litmus store` inspection, garbage collection, and integrity-checked pack/unpack; `analyze --format github`; and historical duration-balanced module sharding when `--shard` is paired with `--reach-from`.
- **Shared-process & codebase hygiene.** Replaces FIFO open/read spin-polling in `SharedWorker` / `FIFOLineReader` with event-driven `O_RDWR` FIFOs and `Process.terminationHandler` wake signaling, strict `Codable` messages, and `Synchronization.Mutex`.
- **Stability contract.** Documented in `docs/stability.md`.
