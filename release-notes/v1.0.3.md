## Behaviour

- An `xcresulttool` summary counts known issues (`withKnownIssue`, `XCTExpectFailure`) in `totalTestCount` but in none of `passedTests`, `failedTests` and `skippedTests`. Litmus required those three to add up to the total, so any suite with a known issue under `xcodebuild` was rejected, and the unmodified run failed with `xcresult summary unavailable (xcodebuild exit 0)`. Expected failures now count as passed, as the per-bundle counts already did.
- Every counter is bounds-checked before any is added, so hostile summaries still cannot overflow.

## Findings that may appear

- Projects whose unmodified `xcodebuild` run failed with `xcresult summary unavailable (xcodebuild exit 0)` now get verdicts.
