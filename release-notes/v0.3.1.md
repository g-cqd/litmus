# litmus 0.3.1

Fixes the simulator helper stalling on XCTest suites with `@MainActor` or `async` cases, and makes stalled runs and test-selection arguments easier to diagnose.

## Findings that may appear

- A hostless iOS test bundle with `@MainActor` or `async` XCTest cases used to stall until its deadline (a `timedOut` unmutated baseline, exit `70`). It now runs, so its mutants are decided.

none

## Consumer steps

- An `--xcodebuild-argument` that selects tests (`-only-testing`, `-skip-testing`, `-only-test-configuration`, `-skip-test-configuration`) runs the tests through `xcodebuild` instead of the simulator helper, which cannot honour it; the run's notes say so.
