## Behaviour

- Shared-process workers' reply reads and the Swift Testing event-stream drain no longer block Swift's cooperative thread pool. That pool has one thread per core; with several shared workers waiting on replies, deadlines, monitors and stops could start late.
- The benchmark (`bench/run.py`, `.github/workflows/bench.yml`) fails only when a tool's binary is missing or Litmus's own cell does not end `ok`; another tool's failure or timeout is reported in its row.
