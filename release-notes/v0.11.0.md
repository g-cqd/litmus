## Behaviour

- One HTML file with its style, script and data inline; its Content-Security-Policy (`default-src 'none'`) allows no network request.
- A directory tree with logic and UI scores per directory and file; the source of each file, read from the subject root at analyze time, with each mutated line marked by its verdicts (survived, not covered, accepted, detected, other).
- Clicking a line opens its mutants: verdict, operator, domain, time, diff, reason, acceptance reason, reaching tests, and copy buttons for `litmus run . --only-id <id>` and `litmus accept <id> --from <run> --reason …`.
- Run data is embedded as JSON with `<`, `>` and `&` escaped, and the script writes it with `textContent` only, so no source text or reason can become markup.
