# litmus 0.6.0 (from 0.5.0)

Completes Phase E: `IndexStoreDB`-backed `TypeOracle` for type-directed collection operators, six census-backed syntactic operators (`nullify-optional-binding`, `negate-is-empty`, `skip-loop`, `swap-break-continue`, `replace-bitwise`, `remove-unary-minus`), computed-property and subscript return mutations, four fault-injection operators (`--fault-operators`), and per-operator effectiveness tables in reports.

## Behaviour

- **Phase E1 (`TypeOracle` and type-directed operators).** Opens `IndexStoreSession` and `IndexQueries` from `analyzerkit` against fresh index units (keyed by relative path so workspace copies resolve against the subject's store), with conservative local/parameter/property type fallback when no store exists. Adds `replace-collection-transform` (`.sorted()`, `.filter(...)`, `Array(x.reversed())`) and `swap-first-last` (`.first` / `.last` on bidirectional collections, never emitting `.last` on `Set` or `Dictionary`).
- **Phase E2 (census-backed syntactic operators and computed-property returns).** Adds `nullify-optional-binding` (explicit, `try`/`await`, and shorthand `if let x` / `guard let self`), `negate-is-empty`, `skip-loop` (`for … where`), `swap-break-continue`, `replace-bitwise`, and `remove-unary-minus`; extends `return-boundary` and `return-constant` to computed properties and subscripts while isolating nested closure return types; wires all new operators into `MutationCensus`.
- **Phase E3 (`--fault-operators`).** Adds `remove-defer` (guarding the `defer` body so baseline scope-exit timing is preserved and lock unlocks are skipped), `remove-cleanup-call`, `weaken-capture` (retaining `weak`/`unowned` captures strongly via a conditional shadow capture and `withExtendedLifetime` while preserving `T?` body types), and `swap-async-order`.
- **Phase E4 (per-operator effectiveness).** Reports per-operator viability, kill/survival counts, accepted counts, score, and mean runtime across JSON, Markdown, and Agent reports.
