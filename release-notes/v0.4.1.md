## Behaviour

- **App-hosted iOS Simulator unit test bundles run through Litmus's simulator helper** across concurrent `simctl spawn` workers, with automatic fallback to `xcodebuild` if a bundle cannot load directly or its baseline needs a launched `UIApplication`. UI test bundles always use `xcodebuild`.
- The simulator test helper is cached per toolchain under `~/Library/Caches/litmus/simulator-helper` and invokes `simctl` directly instead of going through `xcrun` on every mutant.
- A shut-down destination simulator (`--simulators 1`) is booted in parallel with the first `xcodebuild build-for-testing` instead of cold-starting on every test invocation.
- Xcode builds and tests pass `-enableCodeCoverage NO` unless `--xcodebuild-argument` explicitly passes `-enableCodeCoverage`.
- Targeted kill confirmation runs single-test confirmations concurrently across workers and deduplicates identical inactive controls per schema, falling back to a serial whole-suite rerun alone whenever a confirmation does not reproduce.
- Transient run-owned build artifacts (`output/artifacts`) are removed once a run finishes unless `--keep-workspace` or `--build-directory` is set.
- `WorkspaceSnapshot` skips `.DS_Store`, preventing Finder metadata from marking evidence stale on macOS.
