## Behaviour

- `--format github-summary` writes Markdown for `$GITHUB_STEP_SUMMARY`: the score and, when both domains ran, logic and UI scores; with `--compare`, the change in points and a list of mutants the earlier run detected that this one does not; then one collapsible diff per survivor and per uncovered mutant (50 of each at most).
- With `--shard-strategy mutant`, suppressed sites are recorded by the first shard only, so `litmus merge` counts them once.
- `run --help` lists every operator and the `all`, `ui` and `fault` groups under `--operators`; the list had stopped at `remove-switch-case`.
- Not in this release: shards still build the whole project. Which test modules a mutant needs is known only after the baseline, so a shard cannot limit its build beforehand.
