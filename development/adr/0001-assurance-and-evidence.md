# ADR 0001 — Evidence-led assurance; no implicit qualification

Status: accepted
Date: 2026-11-02

## Context

The requested principles are high performance, resilience and reliability, with military/high-criticality engineering
rigour. The existing investigation contains real measurements, useful probes and some conclusions stronger than their evidence.

## Decision

Adopt named reliability requirements and a traceable evidence record. Preserve uncertainty in the data model and exit status.
Use “initial implementation” until operational gates pass. Never describe a green unit suite as safety certification.
Keep a white paper (<200 lines), one decision per ADR, append-only dated diary entries and roadmap evidence gates.
Use the provided tasks/ideas tools for active work and user proposals. Do not invent a safety standard or certification target.

## Consequences

More conservative verdicts and more negative-control runs cost time. That cost is acceptable until evidence supports a
cheaper policy with the same reliability. Standards-specific qualification is a separate project requiring independent work.
